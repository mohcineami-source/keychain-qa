    Overrides (query string)

    ?pixel= pixel ID · ?price= value · ?currency= ISO code · ?txn= transaction ID · ?auto=0 don't fire on load (button only)

    Each load generates a fresh transaction ID unless you pass ?txn=, so Snap won't dedupe repeat tests into one event.

    Before you point ads at anything

    Take this page down once the pixel is verified. While it's live, every visitor is reported to Snap as a completed purchase — that trains the optimizer on fake conversions and inflates the purchase count in Ads Manager. It's a bench tool, not something to leave on a domain that receives traffic.
